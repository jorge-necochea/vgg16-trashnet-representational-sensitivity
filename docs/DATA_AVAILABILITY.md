# Suggested Data Availability Statement

The original TrashNet dataset analyzed in this study is publicly available at
https://github.com/garythung/trashnet. The analysis code, execution notebooks,
image manifests, derived metrics, summary tables, software environment records,
and supplementary results are publicly available at
https://github.com/jorge-necochea/vgg16-trashnet-representational-sensitivity.
The original TrashNet images are not redistributed in the study repository.
The transformed image collections and full embedding matrices can be regenerated
from the public source dataset using the released workflow.
