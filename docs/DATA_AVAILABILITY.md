# Suggested Data Availability Statement

The original TrashNet dataset analyzed in this study is publicly available at
https://github.com/garythung/trashnet. The analysis code, image identifiers,
derived image-level metrics, summary tables, and supplementary results are
publicly available at
https://github.com/jorge-necochea/vgg16-trashnet-representational-sensitivity
and will be archived in Zenodo before publication [DOI to be added]. The
repository does not redistribute the original TrashNet image files. The
original TrashNet files used in the analysis are JPEG images; therefore, the
PNG-stored transformed images are lossless storage derivatives of already
lossy JPEG sources.
