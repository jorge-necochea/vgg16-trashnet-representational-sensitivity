# Supplementary-material source map

The revised supplementary file for journal resubmission should be assembled
from the released source tables and figures below.

- R1 baseline, adjusted-sensitivity, and CKA material:
  `data/summary_tables/r1/` and `figures/r1/`.
- R3 brightness-clipping and preprocessing audit:
  `data/summary_tables/r3/` and `figures/r3/`.
- R4 complete intensity-ordering results and rotation exceptions:
  `data/summary_tables/r4/` and `figures/r4/`.
- R5 cross-class peripheral-gradient, object-extent, partial-correlation, and
  interaction analyses: `data/summary_tables/r5/`, `figures/r5/`, and the
  image-level source files in `data/derived_metrics/r5/`.
- The aggregate and complete matched JPG–PNG results are in
  `data/summary_tables/storage_format_aggregate_summary.csv` and
  `data/summary_tables/storage_format_matched_822_complete.csv`, respectively.

`Supplementary_Materials_VGG16_TrashNet_Revised.docx` is the **consolidated
20 October 2026 supplementary document** prepared for journal resubmission.
It contains Figures S1–S8 and Tables **S1–S13**. Tables S11–S13 report the
822-image aspect-ratio/preprocessing robustness control using the source files
in `analysis/robustness822/`. The old S1–S10 file was superseded, not retained
as a second active supplement. Main-text figures
are not duplicated except where historical subset results serve as a defined
secondary analysis.
